# Bonus deck lists

Ready-to-paste item lists for rapid-fire bonus games. In the game:
Set up questions → Bonus games → Add a bonus game → paste a file's lines into
"Add text items" → Add these → Save bonus game.

Each line is `shown on the TV = answer`. Answers with a "/" list every
accepted answer (e.g. transfers); the host judges what counts.

Picture decks (logos, celebrities, Call of Duty maps, Pokémon, house banners):
upload the images with "Or add pictures". Name each file after its answer
(`nike.png`, `nuketown.jpg`, `house-stark.png`) and the answer fills itself in.

## Ready-made picture decks (in images/, not saved in git)

Downloaded for private party use (other people's artwork; don't publish
them). Each folder is one deck; upload a whole folder at once.

- images/pokemon: 60 Pokémon, about 60% gen 1, 30% gen 2, 10% gen 3
- images/logos: 101 brand logos (none that spell their name): everyday brands, harder ones (car badges, airlines, apps) and fashion/beauty symbols (Chanel, Fendi, Lacoste, Hermès, Louis Vuitton…)
- images/celebrities: 43 celebrity photos (from Wikipedia)
- images/got-house-banners: 27 Game of Thrones house banners
- images/cod-maps: 90 Call of Duty maps from MW2, Black Ops, Black Ops 2, Black Ops 3 and MW3
