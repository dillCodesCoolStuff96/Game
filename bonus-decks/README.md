# Bonus deck lists

Ready-to-paste item lists for rapid-fire bonus games. In the game:
Set up questions → Bonus games → Add a bonus game → paste a file's lines into
"Add text items" → Add these → Save bonus game.

Each line is `shown on the TV = answer`. Answers with a "/" list every
accepted answer (e.g. transfers); the host judges what counts.

Picture decks (logos, celebrities, Call of Duty maps, Pokémon, house banners):
upload the images with "Or add pictures". Name each file after its answer
(`nike.png`, `nuketown.jpg`, `house-stark.png`) and the answer fills itself in.
